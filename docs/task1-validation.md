## 与课件的差异

课件指定 ARM GCC 10.3-2021.10。该版本在自动执行环境中报 Windows 错误 623（系统 DLL 重定位），所以采用官方 64 位 14.3.Rel1 作为可用方案。旧版本已保留在本机，但没有确认它在普通用户终端中的表现。

检查脚本分别记录功能检查和固定版本匹配结果，不能将功能通过解释为完全满足课件指定版本。

## 后续任务的前置问题

QEMU 板型列表没有 `stm32f103`，存在 `stm32vldiscovery`、`lm3s6965evb` 等 Cortex-M3 板型。任务 2 开始前应确认课程是否提供定制 QEMU，或选择实际支持的板型，并同步适配启动代码、链接脚本和外设驱动。

## 验证边界

- 编译检查只生成目标文件，未生成可启动的 FreeRTOS 固件。
- CMake 只进行了版本验证，尚未构建完整固件工程。
- 串口测试使用 `loop://`，尚未验证 QEMU 和 Python 通信。
- 物理测试使用无窗口模式和方块，尚未验证六轴机器人模型或 GUI。
- 未进行实物硬件或真实实时性能测试。
